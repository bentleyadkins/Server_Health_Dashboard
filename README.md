## Setup for python code

### Windows Setup (Command Prompt)

1. Install python 3.12.10
```
py install 3.12.10
```

2. Create the .venv
```
py install 3.12.10
```

3. Activate .venv
```
.venv\Scripts\activate
```

4. Run requirements.txt for packages
```
pip install -r requirements.txt
```
